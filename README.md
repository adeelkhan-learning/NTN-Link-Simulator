# 5G-NR NTN Link Budget Emulator

A real-time simulation tool for calculating Link Budget parameters for Non-Terrestrial Networks (NTN), including LEO orbit propagation, delay, Doppler shift, and visibility masking.

## Features
* **Real-Time Propagation:** LEO satellite orbit visualization using spherical coordinates.
* **Link Budget Analytics:** Dynamic plotting of elevation, propagation delay, and Doppler shift.
* **3GPP NTN Bands:** Support for FR1 (L/S-Band) and FR2 (Ka-Band) configurations.
* **Customizable UE:** Interactive map-based User Equipment (UE) positioning.

## How to Run
Simply open the index.html file or click here https://adeelkhan-learning.github.io/NTN-Link-Simulator/
